# Pokémon Bank - Cajero automático (ATM)

Proyecto de Cátedra Fase 1 - Lenguajes Interpretados en el Cliente (LIC941)
Universidad Don Bosco

Propuesta de interfaz web (Front End) para un cajero automático.

## Pantallas
- `index.html` - Login con PIN de 4 dígitos (PIN de prueba: 1234)
- `acciones.html` - Datos del usuario y transacciones: depositar, retirar, consultar saldo y pagar servicios
- `historial.html` - Historial de transacciones por tipo y monto
- `grafico.html` - Gráfico de transacciones por tipo

## Estructura
- `css/` - estilos propios
- `js/` - lógica en JavaScript: datos en LocalStorage, login, transacciones, validaciones, mensajes y comprobante
- `images/` - logo
- `ejemplos/` - ejemplos de librerías (SweetAlert y Chart.js)

## Tecnologías
HTML5, CSS3, Bootstrap 4.6 (responsive) y JavaScript con LocalStorage
